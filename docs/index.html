Polycarpic documents

The four phase artifacts, the kickoff record, and the issue board

Served by: scripts/serve-docs.sh (or ./scripts/serve.sh for docs + board together) Comments: the inline widget on each doc writes to docs/<DOC>/comments.md; /refine-doc <DOC> addresses them

Phase artifacts

  • Product Requirementsdocs/PRD/

    What we are building and for whom. Owner: product-manager.

  • Architecture & Infrastructuredocs/ARCH/

    Layer model, stack, data flow, deployment topology. Owner: architect.

  • Security & Compliancedocs/SECURITY/

    Threat model, trust boundaries, controls catalog. Owner: seceng.

  • Infrastructure & Operationsdocs/INFRA/

    Targets and topology, keys and TLS, CI/CD, disaster recovery, deployment and operations runbooks. Owner: devops-engineer.

  • Design System & UXdocs/DESIGN/

    Tokens, flows, styled screens, component reuse map. Owner: ux-designer.

Tracker

  • Cairn boardprocess/cairn/

    Majors, milestones, and issues as a Kanban (list, dashboard). A separate server on port 8766: start it with /cairn, or ./scripts/serve.sh starts it alongside this one. If the link fails, the board server is not running.

Source records

  • Project kickoffdocs/project_kickoff.md

    The operative kickoff record: vision, scope, and every architecture and workflow decision.

  • Project manifestodocs/project_manifesto.md

    The original brief, frozen as written.
