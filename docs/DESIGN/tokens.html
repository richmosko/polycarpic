How to read this page

Each row is one CSS custom property from tokens.css. The two swatches show its literal value in Light (:root) and Dark (.dark) mode side by side — not a toggle, so you can compare both at once. "Used for" is deliberately short; follow the link in design-system-spec.md for the full derivation, contrast figures, and the job definition for tokens (like --brand/--brand-2) that are only safe to use in specific places.

8. Typography

TokenSampleUsed for
--font-sans Aa — $12,480.55 Everywhere — body, buttons, inputs, table cells, headings, stat values. One grotesque sans for the whole app, confirmed against both reference products' actual app UI (their serif is marketing-only).

--font-mono NET WORTH · AAPL · #10294 Origin's own measured pattern — uppercase, letterspaced eyebrow labels, account numbers, ticker symbols, tabular figures. Never body copy.
