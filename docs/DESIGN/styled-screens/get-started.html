Set up your own instance

Four steps, about half an hour on a fresh server.

  1. Requirements
    • A Linux server you control: a small VPS is enough.
    • Docker with Docker Compose.
    • A domain name pointed at the server, for HTTPS and invite links.
    • An email provider API key, so the instance can send invites.
  2. Deploy

    Fetch the release, set your domain and email key, and start the stack. PostgreSQL runs inside it.

    git clone https://github.com/richmosko/polycarpic.git
cd polycarpic
cp .env.example .env      # set DOMAIN and EMAIL_API_KEY
docker compose up -d
  3. First operator sign-in

    Open your domain and sign in with the operator account the setup created. You land on Membership setup: create your first entity (a Person, Trust, Business or Household).

  4. Invite members

    On Entities, choose Invite member. Each person you invite receives a link that opens Sign up on your instance, with their invite already filled in.
